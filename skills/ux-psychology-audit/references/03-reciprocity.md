# 3. Reciprocity (give before you ask)

**Idea:** When someone gives us something first, we feel a pull to return the favor. Apps that ask for an email or account before delivering any value feel like toll booths. Deliver real value, then ask.

**Evidence (illustrative):** Cialdini ranks reciprocity among the strongest persuasion drivers. Free samples can lift purchases substantially (the "up to 2,000%" figure is anecdotal). Examples: Costco samples, Spotify trial, Notion's generous free tier.

## Checklist
- What does the user get before the first ask (signup, email, payment)?
- Is the pre-signup value genuinely useful (a real partial result, a working tool, a preview) rather than a teaser?
- Is the ask proportional to what was given?
- Does the gate come at a moment of earned interest, with a clear reason ("Save your report")?
- Can the user see the shape of the full value they'd unlock?

## Red flags
- Blurred or locked results after the user already invested effort (hostage pattern).
- "Create an account to continue" as the first screen.
- Email wall before any content.
- A free tier so crippled it gives no real value.

## Recommendation pattern
Reorder: value → proof → ask. Show a real partial result (score, top issues, what passed), then gate the depth (full report, export, history) behind signup, with a one-line reason.

## Scoring
0 = ask before any value · 1 = token teaser · 2 = real value but ask is abrupt or unexplained · 3 = real value first, proportional, well-timed ask
