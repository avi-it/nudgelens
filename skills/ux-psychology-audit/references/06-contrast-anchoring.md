# 6. Contrast Effect & Anchoring

**Idea:** The brain judges value relative to what it saw just before. A $50/month add-on looks big alone ("$600 a year") and tiny next to a $1,900 laptop ("just 2.6%"). The first number becomes the ruler.

**Examples:** Restaurants list a $90 steak so a $40 salmon looks reasonable. Pricing tables with a high-priced tier make the middle tier look balanced.

## Checklist
- Is any price/cost shown in isolation?
- What does the user see immediately before the price (product total, higher tier, annual vs. monthly)?
- Are add-ons presented in the context of the main purchase and as a relative amount (percent, per day, per use)?
- In pricing tables: is there a deliberate anchor tier, a highlighted recommended plan, and a comparison that is truthful?
- Is the reference price real (a price actually charged), not inflated?

## Red flags
- Add-on offered on a separate page, with no context.
- Cheapest option shown first, so everything else looks expensive.
- Fake "was $X" strike-through prices (dark pattern and often illegal in consumer law).
- Reframing a recurring charge as tiny ("pennies a day") to hide the real total. Show the true total as well.

## Recommendation pattern
Reorder so the larger, true reference comes first → place add-ons next to the main item with a relative label → highlight the plan you recommend → always keep the actual total visible.

## Scoring
0 = costs shown in isolation · 1 = incidental context · 2 = relative framing but the anchor is weak or the order is wrong · 3 = deliberate, honest anchor and relative framing, total still clear
